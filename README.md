Major update

we are raising our first pull request in this repository

1. git clone
2. git checkout -b name-of-feature-branch
3. make all changes we want
4. git add (those changes) - or, we can use the version control tab in cursor
5. git commit -m "your commit message goes here" - those changes
6. git push - those changes
7. raise a pull request (aka PR)
8. ask for a code review, then merge your code in once approved
9. then checkout the main branch
10. git pull - on the main branch to ensure you pull the new code in
